# Workshop Minigame

Emile Rabinovich



Banana Rescue 



Banana Rescue is a game where you play as a monkey jumping through the obstacles of a dangerous volcano in order to same its lost bananas. Made by me, Emile, in two weeks. 



WASD to move, SPACE to jump. 



* I made moving platforms
* player movement
* level tracking system to tell what levels have been completed
* lava spouts
* UI elements
* platforms spawners
